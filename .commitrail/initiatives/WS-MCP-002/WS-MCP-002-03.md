# WS-MCP-002-03 - Administrative read projections

- Initiative: `WS-MCP-002`
- Durable disposition: `Complete`
- Intended merge outcome: Add six fixed public-API read tools to the independent MCP adapter.

## Intent

Let authorized human callers inspect permission and role definitions, administrative
grants, and bounded actor/identity projections before later mutation tools.

## Current behavior

PR #438 delivered three self-service tools. Main at `7f8acfaf2` exposes the six
selected GET operations in `backend/app/modules/authorization/router.py`.
The API owns admission, current role/scope decisions, pagination validation and privacy.

## Bounded change

  six selected OpenAPI snapshots, focused tests and installed-process parity.
- `.github/workflows/mcp.yml`: nine-tool catalogue assertion and integration selection.
- This record, initiative overview/index and affected roadmap and MCP README.

### Not allowed

  in the installed adapter. Test-only public API fixtures may bootstrap authority.

  mutation tools, generic HTTP tool, resources or prompts.
- No new auth/session system, dependency upgrade, deployment claim or gate weakening.

## Design and decisions

Expose exactly `permissions_list`, `admin_roles_list`, `admin_grants_list`,
`actor_admin_grants_list`, `actor_get` and `actor_identity_link_get` with the
`workstream_` prefix. Reuse bounded HTTP/error handling and selected schema validation.
Caller bearer remains request context and is forwarded unchanged. Tool inputs are
closed and typed; query omissions stay omitted so backend defaults remain authoritative.
UUID selectors are validated before fixed-path dispatch. Cursors remain opaque and
are forwarded without decoding or normalization. Return only the API's declared
projection; never return extra contact or identity-subject fields.
