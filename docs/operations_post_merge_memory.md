# Historical Loop-Memory Operations

The signed loop-memory, explicit-start, and recovery-certificate runtime has
been retired.

Git and GitHub are now the source of truth for commits, checks, reviews, and
merges. Planning and review artifacts under `.agent-loop/` are durable context,
not live authority. A failed or stale derived record must not block
implementation, pull-request creation, or unrelated initiatives.

Historical `automation/loop-memory` content may be retained as an audit archive,
but no workflow writes it and contributors must not use it as a start gate.

For current contribution instructions, see [CONTRIBUTING.md](../CONTRIBUTING.md).
